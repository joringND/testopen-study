## 二、核心知识点

### 1. 运算符

```python
# 比较运算符
==  !=  >  <  >=  <=

# 逻辑运算符
and   # 且：全部满足才为 True
or    # 或：满足一个即为 True
not   # 取反
```

### 2. 三种结构

```python
# 单分支
if 条件:
    代码

# 二选一
if 条件:
    代码A
else:
    代码B

# 多分支（今天重点）
if 条件1:
    代码1
elif 条件2:
    代码2
elif 条件3:
    代码3
else:
    兜底代码
```

### 3. 铁律：缩进

- `if` 条件后必须加**冒号 `:`**
- if 下面的代码块靠**缩进**（4 空格/Tab）表示归属，同一块缩进必须一致
- 不缩进 = 不属于 if，任何情况都执行

## 三、执行逻辑（最重要）

**if-elif-else 从上往下找第一个成立的条件，命中即执行、执行完整个判断结束。**

⚠️ 判断顺序必须"先严格后宽松"：

```python
# ✅ 正确：先判断最严的条件
if score >= 90:
    print("优秀")
elif score >= 85:
    print("良好")
elif score >= 60:
    print("及格")

# ❌ 反例：宽条件在前，后面的分支全是死代码
if score >= 60:      # 90 分在这就命中了
    print("及格")
elif score >= 90:    # 永远执行不到
    ...
```

> 记法：像安检通道，先让"最高要求"的人过，再逐级放宽。

## 四、优化技巧：能兜底就兜底

```python
# 先判断最严格的组合条件，剩下的用 elif / else 自动排除
if username == "admin" and password == "123456":
    print("登录成功")
elif username == "admin":        # 走到这说明密码已不对
    print("密码错误")
else:                            # 走到这说明用户名不对
    print("用户名不存在")
```
